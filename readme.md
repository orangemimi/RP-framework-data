# RP-FRAMEWORK-DATA

This repository contains the data and notebooks used to reproduce the
figures, tables, and case-study results reported in the manuscript
*Quantifying reproducibility to support reliable geo-modelling
research*.

## Repository Structure

### 1. `Figures/`

#### 1.1 `Figures/fig.ipynb`

Generates the figures used in the main manuscript and Supplementary
file, including:

-   **Fig. 2**
-   **Fig. 6**
-   **Fig. 7**
-   **Fig. 9(a--d)**
-   **Fig. S1**
-   **Fig. S2**
-   **Fig. S3**

> Note: The figure for **Case 1** is generated by the Case 1 evaluation
> notebook (`case1/2Evaluation.ipynb`).

#### 1.2 `Figures/case-comparison.xlsx`

Contains the data used to generate **Fig. 2**, derived from the CREST
hydrological model. The original CREST model code and data are subject
to access restrictions and cannot be publicly shared. This file is
provided to support reproduction of the figure.

#### 1.3 `Figures/sequence-discrete-initial/`

Contains `pred_nonoisy_initial.csv`, which is copied from:

`table2&3/2_Sequence/Discrete/no-noisy/initial-out/pred_nonoisy_initial`

This file provides the discrete sequence output used as input for figure generation.

#### 1.4 `Figures/sequence-continuous-initial/`

Contains `pred_nonoisy_initial.csv`, which is copied from:

`table2&3/2_Sequence/Continuous/no-noisy/initial-out/pred_nonoisy_initial`

This file provides the continuous sequence output used as input for figure generation.

#### 1.5 `Figures/repro-out/`

Contains reproduced output data used by `fig.ipynb` for figure
generation.

### 2. `table2&3/`

This folder contains the results used to produce **Table 2** and **Table
3**.

The results are organised according to output structure and data type:

-   **`1_Point/`**
    -   `Continuous/`
    -   `Discrete/`
-   **`2_Sequence/`**
    -   `Continuous/`
    -   `Discrete/`
-   **`3_Field/`**
    -   `Continuous/`
    -   `Discrete/`

Within each subfolder, the two experimental conditions are organised as:

-   **`no-noisy/`**\
    Corresponds to **Condition A: Aleatory variability only** (Table 2).

-   **`has-noisy/`**\
    Corresponds to **Condition B: Aleatory variability with a controlled
    provenance-gap proxy** (Table 3).

### 3. `case1/`

This folder contains the reproduction and evaluation pipeline for **Case
1**.

#### 3.1 `case1/1Reproduction.ipynb`

Reconstructs and executes the workflow used to reproduce the original
study. Run all cells from top to bottom. The reproduced outputs are
saved to `case1/reoutputs/`.

#### 3.2 `case1/2Evaluation.ipynb`

Evaluates the reproduced outputs using the proposed framework. Run all
cells from top to bottom. The evaluation outputs are saved to
`case1/evaluation-out/`.

> Note: The **Case 1 figure** and the corresponding **Case 1 values**
> reported in the manuscript are generated by this notebook.

#### 3.3 `case1/inputs/`

Contains the original data provided by the source study and used as
inputs for reproduction.

#### 3.4 `case1/reoutputs/`

Contains the reproduced outputs generated by `1Reproduction.ipynb`.

#### 3.5 `case1/evaluation-out/`

Contains the evaluation outputs generated by `2Evaluation.ipynb`.

### 4. `case2/`

This folder contains the reproduction and evaluation pipeline for **Case
2**.

#### 4.1 `case2/1Reproduction.ipynb`

Reconstructs and executes the workflow used to reproduce the original
study. Run all cells from top to bottom. The reproduced outputs are
saved to `case2/out/`.

#### 4.2 `case2/2Evaluation.ipynb`

Evaluates the reproduced outputs using the proposed framework. Run all
cells from top to bottom.

> Note: The corresponding **Case 2 values** reported in the manuscript
> are generated by this notebook.

#### 4.3 `case2/Prediction_data.xlsx`

Contains the original data provided by the source study and used as
inputs for reproduction.

#### 4.4 `case2/out/`

Contains the reproduced outputs generated by `1Reproduction.ipynb`.

-   **`out/outputs.csv`** contains the original experimental results
    from the source study and is used as the baseline for comparison.

## Notes

-   Folder names follow the output taxonomy used in the manuscript:
    **Point / Sequence / Field × Continuous / Discrete**.
-   `no-noisy/` corresponds to **Condition A (aleatory variability
    only)**.
-   `has-noisy/` corresponds to **Condition B (aleatory variability with
    a controlled provenance-gap proxy)**.
-   The folder names `no-noisy` and `has-noisy` are retained from the
    original experimental implementation.

## Quick Start

1.  Run `Figures/fig.ipynb` to reproduce the main and supplementary
    figures generated from the simulation experiments.
2.  Use the corresponding folders under `table2&3/` to locate the
    results for **Tables 2 and 3**.
3.  Run `case1/1Reproduction.ipynb`, followed by
    `case1/2Evaluation.ipynb`, to reproduce and evaluate **Case 1**.
4.  Run `case2/1Reproduction.ipynb`, followed by
    `case2/2Evaluation.ipynb`, to reproduce and evaluate **Case 2**.
